# Wish 电商详情页设计 Skill

将 PDF、Excel、策划截图、右侧创意参考、产品白底图、品牌资料、首屏 KV 或短版灰板，转化为可验证、可批量延展的长版或短版电商详情页。

## 核心能力

- 逐页读取策划稿的文字层、图片层、批注、箭头、引线与右侧参考图
- 将每屏要求转化为对象数量、连接拓扑、中心轴、空间锚点与跨屏接口
- 锁定产品包装、SKU 数量、规格、Logo、关键文字与视觉主次
- 用视觉 DNA 合同统一构图、材质、光线、色彩、字体、Icon 与信息密度
- 长版支持前三屏确认、分组延展、跨屏连续设计与正式长图合成
- 短版／立购台严格锁定灰板尺寸、两侧白边、模块位置和样式，只填充指定区域
- 通过结构、视觉、内容三轮 QA 阻断错位、漏项、文字漂移与美感降级
- 支持含文案正式版，以及按需输出保留产品与场景的无文案信息版

## 使用方式

在支持 Skills 的 Codex 或 ChatGPT Work 环境中调用：

```text
@Wish 电商详情页设计
根据这份策划稿、产品图和灰板，制作一套长版电商详情页。
```

短版／立购台任务：

```text
@Wish 电商详情页设计
严格保留灰板两侧白边、模块位置和文字样式，只补充指定区域的创意画面。
```

定向返修：

```text
@Wish 电商详情页设计
重新核对第 03、04 屏的跨屏管道接口和人物倒液动作，只修复结构错误并保持已确认视觉 DNA。
```

## 工作流程

1. 素材预检：完整读取策划、产品、灰板、KV 与参考图。
2. 结构建模：为每屏建立对象数量、连接关系、锚点、共享轴与跨屏接口合同。
3. 视觉锁定：确认首屏 KV 或三套视觉方向，形成统一视觉 DNA。
4. 分屏生成：长版先确认前三屏再分组推进；短版锁定灰板，仅填充允许区域。
5. 三轮 QA：依次检查结构与物理关系、视觉设计质量、内容与产品身份。
6. 正式交付：归档确认分屏、拼接长图、输出清单，并按用户要求决定是否制作无文案信息版。

## 关键设计原则

1. 严格按策划，不等于照抄参考图；保留创意机制、动作、因果、数量、拓扑和证据布局，同时原创重构镜头、材质、光线与视觉表皮。
2. 元素齐全不代表通过；对象数量、物理连接、中心轴、空间关系、设计质量和文字身份必须同时正确。
3. 用户指出漏看策划、结构错位或整体美感不合格时，立即暂停后续屏，回到策划源和生产合同重建。
4. 跨屏连续内容必须组合设计和拼接验收；单屏正确但上下接口断裂仍判失败。
5. 不新增策划未提供的卖点、数据、机构、报告编号、认证、脚注、规格或承诺。
