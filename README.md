# Wish 电商详情页设计 Skill

把策划稿、已有创意素材和产品资料转成连贯、准确、可交付的电商详情页，支持长版详情页、短版立购台、单屏优化、多 SKU 合集、首屏延展、局部修图和去文案版本。

## 这次版本更新

- 按 GPT-6 Astra 的任务统筹方式处理素材、屏序、创意、确认节点和返修范围。
- 以现有创意素材的使用权限为准：用户指定直接使用的场景优先排版，素材不足或内容不匹配时再补充生成。
- 区分首屏创意标题与内页正常字体，内页优先保证信息层级和手机端可读性。
- 统筹整套长图的节奏、底色、场景承接和跨屏接口，避免每屏像独立海报。
- 建立产品身份与多 SKU 对应关系，检查包装、香型、数量、比例、角度和纸盒对应。
- 使用当前内置图像生成与编辑入口，按 Images 2.5 的能力组织生成和局部修改；实际参数以当前工具为准。
- 支持去文案时保留包装原生文字、Icon 或完整 UI，具体范围跟随用户指令。

## 适用任务

- PDF、Excel、策划截图、右侧参考图转详情页
- 旧长图统一视觉和排版
- 已有场景图直接使用与重新排版
- 首屏 KV 延展第 02 屏及后续屏
- 短版灰版／立购台填充
- 多 SKU 合集与真实使用场景
- 局部包装、材质、文字、背景和构图修正
- 正式版、无文案版和长图打包交付

## 工作方式

1. 读取任务范围内的策划、产品身份图、已确认 KV、灰版、场景素材和用户批注。
2. 建立屏序与素材映射，记录直接使用、允许编辑、仅供参考、身份基准和跳过屏。
3. 确定每屏的传播目标、画面层级、字体分工、产品关系和上下屏衔接。
4. 按用户要求先做方向、首屏、02—03 屏或前三屏；已明确方向时直接推进。
5. 通过内容与产品、结构与动作、设计质量、长图连续性检查后交付。
6. 按用户要求输出独立分屏、正式长图、去文案版本和 ZIP。

## 素材使用原则

- 正式策划决定事实、顺序、文案和明确创意机制。
- 产品原图决定包装、标签、SKU、规格、角度和关键外观。
- “直接使用”表示复用实际场景，可裁切、缩放和排版；不能把重新生图当作原图复用。
- “参考图”需要区分学习风格、构图、机制还是材质，不自动照搬成品。
- 缺少证书、报告、数字或包装细字时标记具体缺口，不猜写、不新增宣称。
