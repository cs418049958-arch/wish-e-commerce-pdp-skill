# Wish电商详情页设计-GPT6 Skill

把策划稿、已有创意素材和产品资料转成连贯、准确、可交付的电商详情页，支持长版详情页、短版立购台、单屏优化、多 SKU 合集、首屏延展、局部修图和去文案版本。

## 当前版本：v2026.10.16（2026-10-16）

本版聚焦第02屏起的背景简化：保留前景创意和主体材质，让文字、产品与卖点清晰可读。01屏KV按创意需求设计。

### 更新说明

1. 第02屏及后续内页强制采用简约、低干扰背景，适用于新生成、延展与获准的背景优化。
2. 保留产品、成分图、质地、人物、使用动作与证据；默认不添加无关散叶、花瓣、碎气泡、粒子和复杂光效，不因留白补装饰。
3. 优先使用品牌适配的纯净底色、柔和渐变、连续色面或简化虚化场景，不强制白底或展台模板。
4. 保留主体高光、体积感与柔和阴影，减少背景强光束、斑驳碎影和复杂反射。
5. 文字区域保持低细节与稳定明暗；信息越密集，背景越安静。
6. 内页继承首屏品牌色、材质与调性，不继承装饰密度；跨屏优先采用底色、留白和渐变。
7. 内页生成提示词明确前景保留项、背景方式及装饰排除项。
8. 增加背景专项验收、减法返修和9项行为验证案例；保留已确认稿、原素材权限和局部修改边界。

## 适用任务

- PDF、Excel、策划截图、右侧参考图转详情页
- 旧长图统一视觉和排版
- 已有场景图直接使用与重新排版
- 首屏 KV 延展第 02 屏及后续屏
- 短版灰版／立购台填充
- 多 SKU 合集与真实使用场景
- 局部包装、材质、文字、背景和构图修正
- 正式版、无文案版和长图打包交付

## 工作方式

1. 读取任务范围内的策划、产品身份图、已确认 KV、灰版、场景素材和用户批注。
2. 建立屏序与素材映射，记录直接使用、允许编辑、仅供参考、身份基准和跳过屏。
3. 确定每屏的传播目标、画面层级、字体分工、产品关系和上下屏衔接；第02屏起明确前景保留项和简约背景。
4. 按用户要求先做方向、首屏、02—03 屏或前三屏；已明确方向时直接推进。
5. 通过内容与产品、结构与动作、设计质量、内页背景专项和长图连续性检查后交付。
6. 整套确认后默认交付《分屏》《分屏_没文字版本》《长图可编辑psd》，包含 PSD 实际导出预览和版本／字体清单；用户指定仅图片或其他范围时从其要求，ZIP 按请求制作。

## 素材使用原则

- 正式策划决定事实、顺序、文案和明确创意机制。
- 产品原图决定包装、标签、SKU、规格、角度和关键外观。
- “直接使用”表示复用实际场景，可裁切、缩放和排版；不能把重新生图当作原图复用。
- “参考图”需要区分学习风格、构图、机制还是材质，不自动照搬成品。
- 缺少证书、报告、数字或包装细字时标记具体缺口，不猜写、不新增宣称。
