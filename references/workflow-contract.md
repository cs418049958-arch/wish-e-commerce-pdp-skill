# 工作流合同

## 目录

1. 输入解析
2. 预检输出
3. 长版流程
4. 短版流程
5. 状态机
6. 交付检查

## 1. 输入解析

### PDF

- 逐页提取文字并逐页渲染。
- 同时检查参考图、箭头、批注、引线、左右对应和整屏示意。
- 建立 `source_page_or_region → screen_id` 映射。
- 未检查全部页前不得进入生成。

### Excel

- 同时读取单元格、合并区域、嵌入图片和图片锚点。
- 不依赖固定列号；按标题、边界、引线和用户说明判断正式区与要求区。
- 把被明确对应到某屏的右侧参考图视为正式创意要求，不是可选灵感。

### 图片

- 产品白底图：产品身份真值。
- 用户完成的首屏 KV：第 1 屏成品和全套视觉母版。
- 短版灰版：像素级尺寸与版式母版。
- 策划参考图：提取创意机制与空间关系，原创重构视觉表皮。
- 竞品图：只学习通用内容逻辑，不复制品牌、文案、独特构图和装饰。

## 2. 预检输出

在生成前向用户说明：

- 长版或短版
- 识别到的屏数与叙事顺序
- 每屏不可丢失的创意机制
- 产品身份基准与风格锚点
- 跨屏连续组
- 真正阻塞的素材缺口或文案冲突

存在策划参考图时，等待用户确认后再生成。

## 3. 长版流程

1. 完整读取素材。
2. 建立每屏生产合同。
3. 运行结构清单校验脚本。
4. 生成三种风格，或锁定用户已有 KV。
5. 建立视觉 DNA。
6. 制作前三屏并输出连续预览。
7. 等待用户确认。
8. 按 2–3 屏分组扩展。
9. 每组执行结构、视觉、内容三轮 QA。
10. 清理终稿目录，拼接正式长图。

## 4. 短版流程

1. 锁定灰版原宽高、纵横比和左右全高白边。
2. 锁定 Logo、标题、数字、Icon、脚注、步骤、模块坐标、圆角、间距和样式。
3. 建立逐模块策划合同。
4. 仅填充允许视觉区。
5. 与灰版叠加检查尺寸和坐标。
6. 通过三轮 QA 后交付完整设计版。
7. 完整设计确认后询问是否需要无文案信息版。

## 5. 状态机

每屏仅允许以下状态：

`parsed → contract_validated → style_locked → generated → structure_passed → visual_passed → content_passed → user_approved → final`

禁止跳级：

- `contract_validated` 前不得生成。
- `structure_passed` 前不得评价风格是否通过。
- `content_passed` 前不得声称 QA 通过。
- `user_approved` 前不得放入正式终稿目录。

用户指出策划偏离、结构错位或新增虚构内容时，将该屏退回：

- 结构/创意错误：`contract_validated`
- 视觉 DNA 错误：`style_locked`
- 单一受保护资产错误：`generated`

## 6. 交付检查

- 正式目录只含批准版本，无历史废稿。
- 分屏两位数命名、同宽、无缺号与重复。
- 长图来自同一批正式分屏。
- 相邻屏无白缝、黑缝、宽度跳变或接口断裂。
- PNG 为母版；平台压缩版另存，不覆盖母版。
- 只有用户明确要求才生成 ZIP。
- 只有用户明确同意才生成无文案信息版。
