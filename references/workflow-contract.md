# 工作流与素材复用

## 输入与范围

- 整套任务：PDF 提取文字并逐页查看渲染图；Excel 检查单元格、合并区域、图片和锚点；截图与压缩包素材逐一建立对应。不可只读取文本而忽略右侧批注、箭头或参考图。
- 单屏修改：读取该屏与必要关联资料，不强制重读无关整套策划。
- 记录任务模式、正式屏数、原始屏序、已确认版本、用户要求保留或跳过的屏、确认节奏和交付形式。
- 不把前一个项目“最后三屏不用做”等要求套入新项目。不把内页默认当作 9:16；沿用用户指定尺寸或根据内容规划同宽、可变高度。
- 仅报告真实阻塞项；模糊小字不可猜为确定文案，列明具体待核对位置。

## 素材角色

| 角色／权限 | 使用规则 |
|---|---|
| 正式策划 | 传达事实、顺序、文案和有明确要求的机制 |
| 产品身份图 | 包装、比例、标签和 SKU 的依据 |
| 直接使用 | 复用原场景，不替换其中产品或重绘；允许范围内进行裁切、缩放和排版 |
| 允许修改 | 指定基底与修改范围，用内置编辑完成；复核保留区域 |
| 仅供参考 | 说明学习风格、布局还是机制，不自动复制成品 |
| 已确认 KV／分屏 | 成品与风格来源；不得擅自重绘或误用旧稿 |
| 灰版 | 原尺寸、白边、坐标与样式的版式母版 |

为已有素材排版建立“screen_id → asset_id → use_policy → 使用区域 → 缺口”映射。
素材不足、不适合文字留白、SKU 不匹配或产品被遮挡时，先寻找其他已提供素材，再判断能否局部编辑，最后才补充新场景。
如果用户要求严格原样使用而排版需覆盖或修改原内容，先提出具体冲突，不把重新生成包装为直接复用。

## 版本与确认

- 记录每屏当前候选、用户确认版本及最终文件；最新用户指令可更新选择。
- `review_mode=checkpoints`：按用户要求停在明确节点。有新风格需要用户选择、尚未授权自行选定时先给可评审方向。
- `review_mode=autonomous`：用户已要求整套推进，必要自检后继续，不逐屏重复确认。
- 用户确认首屏不等于确认后续所有候选；自主验收完成与用户确认分别记录。
- 用户反馈出现时先回答或纳入修改，再继续原目标。回看被影响屏，不丢失排除项与已完成成果。

## 短版灰版

读取并锁定原宽高、两侧全高白边、模块坐标、圆角、间距、Logo、文字区和样式。只填充允许区域。
输出后与灰版叠加检查；坐标与文字区漂移则定向修复。整屏编辑无法稳定保留固定区时说明具体限制，不声称像素级复刻成功。

## 去文案与交付

“去文字”默认仅删除页面排版标题、正文、数字、角标和脚注，保留包装原生文字、产品、场景、Icon 与 UI 图形。用户明确要求删除 Icon、去场景或 UI 保留时据其原话调整。
用户特别说“UI保留”时，把完整 UI 视为保留区，默认连同其中原有标签／界面文字保留，除非用户明确要求删除 UI 内文字。
去文案后修补原文字区域并检查伪字、残影、背景断裂。不得将“去文案”解释成去产品标签。

正式目录仅放被选定的可交付版本。默认同宽 PNG 分屏与正式长图，必要时附简短屏序说明；ZIP、平台压缩版和无文案版按请求制作。压缩版另存，不覆盖母版。
