# 跨屏连续合同

## 目录

1. 触发条件
2. 接口字段
3. 生成顺序
4. 验收

## 1. 触发条件

出现以下任一情况时建立跨屏合同：

- 同一管道、光轨、人物、空间或场景跨越两屏
- 策划要求“连续过渡、上下串联、延续”
- 上一屏物体从底边出屏，下一屏需从顶边入屏
- 长图接缝本身承担叙事

## 2. 接口字段

每个接口记录：

- `continuity_group`：例如 `03-04-pipe`
- `object`：连续对象
- `from_screen`、`to_screen`
- `edge_from=bottom`、`edge_to=top`
- `normalized_x`：0–1 横向位置
- `diameter_or_width_ratio`
- `material`
- `lighting`
- `direction`
- `occlusion_forbidden`：接口附近禁止的横梁、封口、卡片或重复物体

## 3. 生成顺序

1. 先画出两屏联合结构草图或文字接口表。
2. 先锁定接口，再分别生成屏内内容。
3. 生成后立即制作无缝连续预览。
4. 相关屏作为一个组合提交 QA；不要先单屏宣告通过。

## 4. 验收

- 出口与入口横向位置误差不超过画布宽度 1%。
- 管径、透明度、折射、边缘高光和光轨方向一致。
- 接缝处无封口、横梁、白缝、遮挡或第二根重复对象。
- 下一屏不重复上一屏已经结束的场景主体。
- 单屏裁切后可读，拼接后物理关系更完整。

任一接口失败时同时返修相关屏，不只移动其中一屏的局部物体。
