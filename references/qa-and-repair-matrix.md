## 1. 三轮 QA

### A. 结构与物理关系

- 对象数量逐项匹配。
- 主体锚点、上下/左右/环绕/前后关系正确。
- 连接图完整；入口、出口和中心轴吻合。
- 人物动作、产品角度、液体方向符合真实物理。
- 跨屏接口连续。
- 禁止对象没有出现。

### B. 视觉与设计质量

- 完整继承视觉 DNA。
- 标题和 Icon 不是默认黑体、普通圆贴或通用素材。
- 第一视觉主体清晰，有构图张力和空间层次。
- 材质、光影和场景质量达到确认样张水平。
- 相邻屏统一但有节奏变化。
- 没有为了“科技感”走向过硬、过蓝或过度特效。

### C. 内容与产品身份

- 正式文案、数字、单位、标点逐字一致。
- Logo、产品名、规格、净含量、包装关键文字正确。
- SKU 数量、包装轮廓、瓶盖/泵头和标签层级不漂移。
- 报告无虚构机构、编号、印章或检测结论。
- 没有策划外脚注、卖点、Icon 或说明。

## 2. 一票否决

- 漏读任何策划页或右侧参考要求。
- 对象数量、连接拓扑、中心轴或跨屏接口错误。
- 以通用卡片、双管分镜或孤立展示物替代策划构图。
- 产品包装事实、关键数字或报告身份错误。
- 标题/Icon/材质明显低于已确认视觉语言。
- 画面内容齐全但缺少基本美感、层级或可读性。

## 3. 返修矩阵

| 问题 | 处理 |
|---|---|
| 构图、数量、拓扑、核心动作错误 | 回到策划源整屏重建 |
| 地漏/管口、人物/产品、液体/入口错位 | 重建连接图，不遮盖修补 |
| 跨屏接口错误 | 相关屏同时返修并重新拼接 |
| 标题、Icon、材质语言降级 | 重新加载完整视觉 DNA 后重建 |
| 单个文字、数字、Logo 错误 | 锁定其他区域，修正受保护资产 |
| 包装关键文字错误 | 优先替换/合成原产品资产；随后复核全部包装信息 |
| 报告出现虚构信息 | 使用可靠原图；否则改无机构抽象证据卡 |
| 画面正确但无美感 | 视觉 QA 失败，重做构图层级与设计语言 |
| 用户指出策划偏离 | 停止后续屏，重开原策划并重建合同 |

## 4. QA 记录

每屏记录：

```text
Screen:
Structure QA: pass/fail + 证据
Visual QA: pass/fail + 证据
Content QA: pass/fail + 逐字核对结果
Protected assets checked:
Continuity preview:
Decision: rebuild / targeted repair / approved
```

只有三轮全部为 `pass` 才能使用“QA 已通过”。
