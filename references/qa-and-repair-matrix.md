# 质量与返修

## 四项验收

1. **内容与身份**：按正式文案逐字核对数字、单位、标点；按产品原图核对 SKU、规格、包装、标签、角度和比例。证书与报告使用真实内容。
2. **结构与动作**：关键对象数量、物理连接、空间关系和使用方式正确。仅对相关画面核对中心轴及流向。
3. **设计质量**：主体清晰，首屏与内页字体分工合理，信息能在手机上读懂；构图、材质、光影、留白与已确认视觉系统相符。常规字体和简约布局可通过。
4. **连续性**：长图整体阅读节奏、前后屏底色、场景接口、标题距离和产品重复情况；本屏局部正确不能代替长图检查。

可在同一次看图中发现多个问题，不强制先完成一轮才允许观察另一轮。脚本通过不等于以上检查通过，不能声称未实际查看的图片已验收。

## 问题与影响范围

| 问题 | 处理 |
|---|---|
| 漏读、错卖点、错 SKU、假数据或错误使用动作 | 停止受影响稿交付与依赖延展，回原始资料纠正 |
| 单个文字、标签或局部材质错误 | 定向编辑，复核相关受保护内容及保留区 |
| 包装参考正确但视角漂移 | 保留当前底图角度，只修目标包装属性 |
| 关键机制或整体连接关系失效 | 从策划与身份参考重建该屏，恢复相关视觉规范 |
| 跨屏接缝错误 | 定位需修改的一侧或双方，修后检查连续预览 |
| 标题太花、背景抢主体或节奏单调 | 针对字体、景深、对比或布局修正，不自动全屏推倒 |
| 小范围装饰瑕疵 | 记录并在交付前修复，不阻断无关屏工作 |
| 小字或证据不可核对 | 标明具体缺口，不猜写，不将待确认稿当终稿 |

用户说“偏离策划”时，暂停依赖错误理解的后续生产，重开对应策划与参考；先定位影响范围，再决定局部修正或重做。
同类问题连续两轮无改善，改变方法或说明实际缺口，不无限生成。

## 记录与放行

每屏简短记录：版本、内容／身份结果、结构结果、视觉结果、连续预览、未解决项、用户确认状态。
只有相关检查实际通过且没有未解决的实质错误，才标记 qa_passed。
用户确认用 user_approved 记录；用户已授权自行完成时可从 qa_passed 进入 final，不虚构用户批准。
局部改稿使该屏回到 generated／repair；重新检查受影响项与保留区，不强制无关屏全部作废。

## 交付前

- 终稿目录与清单选中版本一致，无旧稿、重号、缺屏。
- 分屏同宽，原始高度与画布比例得到保留，平台压缩另存。
- 长图由同批选中分屏生成；检查拼接顺序与总高度。
- 去文案版本没有误删包装、Icon 或用户要求保留的 UI。
