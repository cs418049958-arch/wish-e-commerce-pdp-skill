# 可编辑长图 PSD 交付

## 触发与完成范围

- 整套分屏全部确认后，默认连续执行：锁定有字分屏 → 逐屏去字底图 → 还原文字排版 → 可编辑长图 PSD → 验收与交付。用户已授权整套自主完成且终稿验收通过时可继续，清单保留真实状态。
- 用户明确只要图片、单屏、预览或仅去文案时按其范围，不强制扩展为整套 PSD；用户直接要求把已有终稿转 PSD 时直接进入本流程，不重走创意审批。
- 已获授权后自主完成例行去字、排版及检查，不逐屏重复索要确认。存在无法识别的文案或必须改动确认设计才能完成的冲突时，仅提出具体缺口，继续不受影响的工作。
- “全部文字可编辑”指页面排版文案，但 01 屏 KV 已确认的艺术字体标题固定保留其原始字形，不转换为文字层；产品包装原生文字、商标和场景内实体标识也保留在原图中，除非用户另有明确要求。背景、产品不默认拆成可编辑三维物体。

## 1. 锁定分屏与文字记录

- 只使用最新确认稿或授权验收终稿，锁定实际文件、版本、屏序、宽高、文案和构图。转换阶段不改写卖点、不重新设计。新文件另存，不覆盖确认稿。
- 去字前逐屏记录所有页面文案：中英文标题、正文、卖点、数字、单位、角标、脚注、页眉页脚、图标说明及香调信息。OCR 仅作辅助，对照原图逐字核对；不猜测模糊小字或纠正未经授权的事实。
- 每个文本块记录屏号、原文（含换行）、原图文字区域坐标、字体或待匹配字体、字号、颜色、字重、字距、行距、对齐、旋转及效果。01 屏艺术标题单独标注为“保留原始图像／不可编辑文字”，不列入待重建文字块；同屏副标题、卖点、角标等其他页面文案仍逐一记录为可编辑文字。优先利用已提供 PSD 中真实文字与样式；避免把同一段落拆成逐字碎层。
- 保持同宽、各屏原高度与既定屏序。尺寸不一致时先查明原因，不拉伸产品或擅自裁掉内容。

## 2. 逐屏生成去字底图

- 先检查已有《分屏_没文字版本》与终稿是否一一对应且合格；有合格文件则复用，仅生成缺失或需返修的屏。
- 通过当前内置图像编辑入口，按 Images 2.5 工作方式以该屏原图为基底去字；调用前读取 image-generation.md 与 prompt-templates.md。遵守工具实际参数，不声称已切换不可选模型。
- 删除待重建的页面排版文案，并自然补全被文字覆盖的背景。01 屏 KV 艺术标题保留原始字形，优先单独提取为透明图像层叠放于纯净底图；如果分离会破坏笔触、光影或背景，就在 01 屏去字底图中保留艺术标题，仅清除该屏其他页面文字，并在清单注明此例外。保持产品数量、包装、标签、角度、位置、大小，场景、光影、配色、构图和跨屏边界。保留非文字 Icon、线条、色块及 UI 图形；仅去字且明确要求 UI 保留时，按 workflow-contract.md 保留界面文字。若同时要求全部页面文字可编辑，则保留 UI 的视觉、图形与布局，去除底图内 UI 文字并原位重建为原生文字层，避免旧字重影；不能擅自把 UI 文字排除在可编辑范围外。用户明确要求连同 UI 原有文字保持原图时，记录其限定范围。
- 提示词明确：仅去除待重建的页面排版文字，保留 01 屏艺术标题原貌、产品包装字与标识；不新增文字、图案或产品，不重构场景，不改变画幅与布局。
- **完整去字结果是唯一底图来源。** 验收后使用整幅图；禁止按 OCR 框、文字边界框、矩形选区或局部蒙版截取去字区域，再贴回旧有字稿。羽化、模糊、纯色遮盖也不能代替连续背景修复：两张图的光照、纹理、渐变可能不同，即使字被去掉，回贴仍会形成矩形补丁。
- 保留实际采用的整屏去字源文件及其 SHA-256。工具返回尺寸变化时先核对构图与几何关系，只做必要的一次整图等比尺寸归一；像素取整差异记录实际尺寸，不用非等比拉伸掩盖漂移。将归一后的完整 PNG 放入《分屏_没文字版本》，记录源图、归一参数、该 PNG 的 SHA-256 和 PSD 对应分组；禁止在入 PSD 或打包时再生成另一套底图。
- 对照原稿，在隐藏待重建文案的状态下逐屏看完整底图，并放大检查原文字区及其外围：残字、伪字、矩形边界、明暗断层、纹理或水纹断裂均须返修。不能只看有字叠加图，也不能以缩略图、文字层数量或结构检查代替底图验收。
- 去字误删包装原生字、商标、报告／证书卡片、Icon、笔刷或其他保留图形时，以原确认稿为参考返修，核对位置、大小及与待叠文字的关系；不能因底图干净就接受设计内容缺失。证据内容仍遵守真实资料及空白占位规则。
- 局部返修使用当前内置图像编辑入口，明确目标区和保留项，获取完整画幅的修正版；验收后用其整屏替换上一版底图，不从修正版裁取文字背景回贴。若工具只返回局部裁图，先取得合格整屏版本，不把该裁图直接作为正式 PSD 底图。
- 用户明确指定的原始 Logo、产品、Icon 或 KV 艺术标题可按已有规则独立透明置入；这类对象层不等于文字背景补丁。不得借“保护原产品／保持像素不变”把旧有字稿的背景重新拼回完整去字图。

## 3. 原生文字与图层重建

- 使用实际支持 Photoshop 原生文字层写入的工具或库生成 PSD。先以代表性中文、英文、换行及样式验证写入能力，再批量制作，避免完成整套后才发现文字被栅格化。
- 除 01 屏 KV 已确认的艺术标题外，其他页面排版文案重建为真正的文字层，可修改内容、字体、字号、颜色与位置。01 屏艺术标题作为图像层保留，命名“KV 艺术标题｜保留原图｜非文字层”，避免再次叠加同文案的文字层。仅有图层名称、OCR 清单、隐藏文字配图或文字截图都不满足要求；智能对象内的文字截图也不算原生文字层。
- 依据确认稿还原位置、换行、比例、字体、字距、行距与对齐。其他屏如有艺术标题，优先保持文字可编辑，尽量通过字体、变换与图层效果还原；字体缺失或手绘字形无法完全复现时，记录替代字体及视觉差异，不承诺像素级一致。01 屏已确认艺术标题遵循保留原图规则，不寻找替代字体。
- 每屏建立独立分组，按屏号与名称命名。组内包含「01 文案｜可编辑文字」「02 装饰／图标」「03 底图」；需要时增加「版式底色」。按语义管理文本块，不逐字拆层。
- 去字底图优先用嵌入式智能对象，避免外部路径失效。简单线条、色块和图标尽量重建为可编辑形状；保留在底图的复杂图形不虚标为可编辑。重建图形前避免与底图已有图形重复叠加，勿将一个简单图标拆成大量碎层。
- 直接嵌入已锁定的完整底图，不在 PSD 构建脚本中按文字坐标重新修补背景。返修已有合格文字 PSD 时优先保留原生文字内容、样式、变换和顺序，只替换受影响屏的整幅底图；不要为了修底图重新 OCR 或改写文字。
- 长图宽度沿用确认稿，高度为所选分屏高度之和。每屏纵坐标等于前面各屏高度累加，零间隙拼接，不重排、不重复、不漏屏。若超出目标 PSD 格式能力，说明限制并提供可行拆分或 PSB 方案，不只更改扩展名。

## 4. 保存后的联合验收

- **底图视觉先行。** 保存并重新打开实际待交付 PSD，隐藏全部待重建的可编辑文案，逐屏导出并实际看图。重点检查标题、正文、数据、脚注及卡片标签背后和外围的矩形接缝、残字、遮盖块、明暗／纹理断层；同时复核包装、卡片、Icon、笔刷及跨屏边界。任一实质缺陷未修复，不放行受影响屏及依赖它的 PSD／预览／交付包。
- **来源与交付一致性。** 将同尺寸、同色彩空间、同位深及同透明合成方式的像素作比较：整屏去字源图经记录的归一操作后，必须等于锁定的无文字 PNG；PSD 隐藏文案后的实际导出必须等于对应 PNG；解压正式 ZIP 后的对应 PNG 也必须一致。保留必要独立对象层时，以锁定的无文案整屏合成为比对基准，并记录这些层的来源。只比 PSD 与 ZIP 两份同样有补丁的图不算通过，必须追溯到验收通过的整屏源图。不得调宽差异容差掩盖补丁；渲染／色彩转换造成差异时查清并统一管线后重验，确实无法完成则说明未验证项，不自称逐像素一致。
- **有字视觉。** 恢复文字显示，把实际 PSD 导出与原有字终稿逐屏对照，检查内容、大小写、标点、数字单位、换行、文字位置、颜色、遮挡、产品身份和跨屏接缝。底图或装饰返修后再看叠字，防止笔刷与标题／数字错位。
- 结构：重新读取 PSD，确认文字是真实文字层、应编辑的页面文案覆盖且 01 屏艺术标题未被文字层重复覆盖、分组顺序与画布尺寸正确、图像资源已嵌入。文字层数量与待重建文本块核对；01 屏艺术标题、包装内文字不计入漏项。
- 编辑：在副本中抽测中文、英文、多行正文及其他屏的艺术标题等代表性文字，修改后保存、重新打开，确认编辑仍保留且显示正常。可访问 Photoshop 时优先在 Photoshop 验证；其他编辑器需报告实际验证环境，不冒称 Photoshop 已验收。
- 没有可用编辑环境时区分“结构检查通过”和“实际编辑未验证”。无法生成原生文字层时明确阻塞与已完成部分，不以栅格 PSD 或脚本冒充最终成品。不能因文件扩展名为 PSD 就宣称可编辑。
- **文件完整性。** 等所有导出完成后再打包；逐张完整解码 PNG／JPG，不只读取尺寸或文件头。若出现部分写入、截断或并发读取未完成文件，改用临时文件完整编码、关闭后原子替换，再重新解码。核验 ZIP 完整性及包内实际内容，排除遗漏、旧版本和临时文件。
- 更新 PSD 底图后重建合并预览缓存，重新打开并核对缓存与实际图层合成一致。交付预览必须来自本次保存后的 PSD，不用另拼图片、旧缓存或单独 imagegen 预览代替。记录各项实际结果，结构通过、视觉通过、编辑抽测通过和 Photoshop 实机验证分别表述。

## 5. 交付结构

- 《分屏》：最新有字确认／授权验收终稿，同宽 PNG，保留原文件名。
- 《分屏_没文字版本》：逐屏对应同名、同尺寸的锁定完整底图；必须与 PSD 隐藏文案导出及 ZIP 内同名文件一致。原始整屏去字输出保留作来源追溯，用户需要时另附。
- 《长图可编辑psd》：长图可编辑psd.psd、长图预览.jpg，以及简洁版本与字体清单。长图预览必须来自交付 PSD 的实际导出，并与正式文件一致。
- 清单记录屏号、原稿版本与状态、原稿和整屏去字源文件、尺寸归一记录、底图文件及哈希、PSD 分组、实际字体及替代、01 屏艺术标题图像层／底图保留方式、可编辑范围例外、底图视觉／来源及交付一致性／结构／编辑验证结果和真实待核对项；无问题不制造待确认项。
- 用户要求时打包 ZIP；排除缓存、旧稿、临时文件与 __MACOSX。保存遵循当前环境文件交付规则，不把成功展示预览当作文件已保存。
