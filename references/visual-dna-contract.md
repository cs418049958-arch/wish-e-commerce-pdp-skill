# 视觉 DNA 合同

## 目录

1. 建立方法
2. 必填字段
3. 重做规则
4. 设计质量否决项

## 1. 建立方法

从用户已确认 KV 或风格样张提取整套可复用规则。不要只写“科技感、家居感、高级感”或“沿用 B 方案”。

## 2. 必填字段

- `canvas_and_grid`：比例、边距、对齐和主要网格。
- `typography`：标题字体性格、粗细、倾角、切角、描边、立体深度；正文层级与行距。
- `icon_language`：2D/2.5D/3D、材质、厚度、圆角、透视、光线、颜色。
- `palette_ratio`：主色、辅色、强调色及大致比例。
- `product_treatment`：尺度、角度、位置、阴影和与场景关系。
- `scene_ratio`：真实摄影、3D、信息图的比例与边界。
- `lighting`：主光方向、软硬、对比度和背景明度。
- `hero_materials`：管道、啫喱、金属、玻璃、泡沫等核心材质的透明度、折射和高光。
- `motifs`：重复使用的光轨、网格、卡片、线条或装饰。
- `information_density`：标题、证据、产品和留白面积关系。
- `forbidden_degradation`：本项目禁止退化的默认样式。

## 3. 重做规则

- 结构重做时同时携带完整视觉 DNA，不得只携带结构修正。
- 单屏局部调整后，复核标题、Icon、材质、色彩比例和信息密度是否漂移。
- 若新稿出现普通黑体、默认圆贴、通用卡片、塑料管质感、蓝色过量或材质极端化，退回 `style_locked` 状态重建。
- 用户对某项视觉反馈定义为全局规则时，更新视觉 DNA，并列出受影响的全部屏。

## 4. 设计质量否决项

- 第一视觉主体不清楚，3 秒内无法读懂卖点。
- 画面只是“普通实景＋展示物”，缺少叙事动线与空间层次。
- 标题、Icon 或证据卡像默认组件，无定制设计语言。
- 为了科技感堆叠高饱和蓝、硬金属、过量网格或不必要光效。
- 相邻屏机械复制同一版式，或为了差异化完全脱离整套视觉。
- 构图、材质与光影明显低于已确认样张质量。

内容正确不能抵消视觉质量失败。
